# Creator Demo Factory

Reusable one-page identity site for cosplayers, VTubers, artists, photographers and other creator-led niches.

## Workflow
1. Contact first. Offer a FREE concept demo with no commitment.
2. Only build after the creator shows interest.
3. Ask for or use only assets the creator authorizes for the demo.
4. Copy this folder into a prospect-specific folder, then edit `config.js` only.
5. Keep the visible `Concept demo • not an official live site` badge until the creator approves the site.
6. Deploy to a temporary preview URL.
7. If the creator wants the finished version, confirm scope and payment before transferring ownership/domain.

## Positioning
Do not sell “a website.” Sell a personal digital home: identity, gallery, links, collaboration/contact and monetization in one place.

## Fast variants
- Cosplayer: gallery, conventions, character list, collaborations, support links.
- VTuber: lore, schedule, latest stream, fanart tags, merch/support, collab contact.
- Artist: portfolio, commission status, prices/TOS link, queue/contact.
- Tattoo artist: portfolio, style, inquiry form, booking/deposit flow.

## Personalization
Change `config.js`: name, tagline, colors, hero image, gallery, highlights, social links and contact URL. Avoid inventing claims or copying private/copyrighted material without authorization.

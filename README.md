# web-demo

Reusable static website concept for small-business outreach.

- Pure HTML/CSS
- Mobile friendly
- No framework, database, API, or build step
- Designed for free static hosting
- Fast to personalize for a prospect

## Personalize

Edit `index.html` and replace:

- business name
- headline/category
- three services
- hours / rating / differentiators
- address / phone / email
- review or business story

Keep the `Concept demo • not a live business website` label visible for prospect-specific previews.

Do not invent factual claims about a real business. Use public verified information or customer-provided material.
